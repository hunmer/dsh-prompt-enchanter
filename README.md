# dsh-prompt-enhancer

给 DSH 输入框加一个「提示词表单」：点输入框右上角的小按钮，弹出一个结构化表单，填什么、输入框里就实时变成什么。

![icon](./icon.svg)

## 为什么

直接把需求丢给 agent 时，问题描述、验收标准、思考深度、要不要提交 git、要不要跑测试，这些信息经常散落在脑子里，写出来的 prompt 每次都不一样。这个插件把它们固定成一张表单，填完即得到一段结构化的 Markdown prompt。

## 使用

1. 在任意会话的输入框右上角，点击 **表单图标**（列表 + 加号）。
2. 第一次打开时，当前输入框里的内容会成为「问题描述」的初始值；已经由本表单生成的草稿会被完整解析回所有字段。
3. 修改任意字段 → 输入框内容立即按新表单重写；清空所有字段 → 输入框清空。
4. 「高级选项」可折叠：执行方式、涉及文件/模块、技术栈、约束与禁止、输出语言、其他补充。填了高级字段时角标显示数量。

底部按钮：

- **从输入框读取**：把输入框现有内容重新解析进表单（适合在输入框里手改后再回填）。
- **清空**：清空表单与输入框。
- **完成**：收起面板（不改动输入框）。

## 预设

面板顶部是预设行，预设保存在浏览器 `localStorage`（键 `dsh-prompt-enhancer.presets.v1`）：

- **切换**：下拉选择预设 → 立即套用其执行选项，输入框同步重写；选「自定义」只取消选中，不改表单。
- **另存为**：把当前表单的「执行选项」存成命名预设；同名保存即覆盖。问题描述、验收标准、其他补充属于任务内容，不会写进预设，切换预设时也不会被覆盖。
- **设为默认**：把选中的预设标记为默认；之后新会话第一次打开表单时自动套用，并同步写入输入框。
- 内置「快速修复」（5 分钟 / 不提交 / 不跑测试 / 直接执行）与「标准交付」（30 分钟 / 提交 / 跑测试 / 先给方案）可设为默认，但不可删除；选中的用户预设右侧有 × 可删除，删除默认预设会同时取消默认。

## 表单字段

| 字段 | 说明 |
| --- | --- |
| 问题描述 | 要做什么，必填语义核心；只有这一项时输出为纯文本 prompt |
| 验收标准 | 怎样算完成 |
| 预期执行时间 | 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 2 小时以上，对应「思考深度：快速 → 极深」 |
| 是否自动提交 git | 是 / 否 / 不指定 |
| 是否需要自动化测试 | 是 / 否 / 不指定 |
| 执行方式（高级） | 先给方案 / 直接执行 |
| 涉及文件、技术栈、约束（高级） | 自由文本 |
| 输出语言（高级） | 跟随项目 / 中文 / English |
| 其他补充（高级） | 自由文本，多行 |

## 生成的 prompt 结构

只有「问题描述」时：

```text
<问题描述原文>
```

有任意其他字段时：

```markdown
## 问题描述

…

## 验收标准

…

## 执行要求

- 预期执行时间：30 分钟（思考深度：深入）
- Git：不要提交，保留改动
- 自动化测试：需要，完成后运行相关测试
- 执行方式：先给出简短方案，确认后再动手

## 补充信息

- 涉及文件/模块：client.js
- 输出语言：中文

参考 #123
```

`##` 标题与条目文案跟随当前界面语言（中文 / English），解析时两种语言都识别。

## 实现要点

- 浏览器半区注册 `conversation.input.overlay` 槽位（`id: prompt-form`，`order: 3`），按钮绝对定位在 composer 卡片右上角。
- 面板 `position: fixed`，右对齐卡片、优先向上展开；卡片位置由 `ResizeObserver` 跟随。
- 表单状态按会话保存在内存里；没有默认预设时，打开面板本身不会改写输入框，只有表单字段变化才写入草稿。设置了默认预设后，新表单首次打开会套用默认预设并同步到输入框。
- 预设存 `localStorage`，只包含执行选项（不含问题描述 / 验收标准 / 补充说明），切换预设不会覆盖任务正文。
- 样式只用 `--dsw-alias-*` 主题变量（含回退值），自动适配明亮/暗色主题；主按钮用 `--dsw-alias-button-primary-fill` + `--dsw-alias-label-primary-foreground`，暗色主题下前景色自动反色，文字始终可见。
- CSS 只注入一次；中英文文案通过 `ctx.locale.register` 注册。

## 安装

在 DSH 里用插件管理器安装本目录：

```text
plugin_manager action=install_bundle target=E:\dsh-plugins\dsh-prompt-enchanter
```

安装后刷新 Web 页面即可看到按钮。

## 开发

```bash
node --check client.js
node --test test/format.test.mjs
```

`test/format.test.mjs` 共 19 项，覆盖序列化 / 反解析往返、纯文本草稿、自由时长归一化、表单状态计数，预设字段提取、空预设拒绝、预设匹配与内置预设文案，以及预设存储的往返、损坏数据降级、非法条目过滤与 32 条上限。
